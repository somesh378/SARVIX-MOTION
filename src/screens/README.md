- `Login.tsx` - Login screen
- `Signup.tsx` - Sign up screen
- `Home.tsx` - Main home/dashboard screen
- `NewProject.tsx` - New project creation screen
- `ProjectEditor.tsx` - Main video editor (future)
- `Profile.tsx` - User profile screen
- `Templates.tsx` - Project templates screen

Each screen is a complete page with its own layout and navigation.
